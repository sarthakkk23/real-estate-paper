Finding · What gets registered

Over all years, about half of Jaipur's RERA projects are apartments, far more than in the rest of the state; since 2025, most new ones are plotted schemes.

Use this when someone applies a Rajasthan-wide trend for plotted colonies to Jaipur, or sizes Jaipur's apartment pipeline.

About half of the projects Jaipur district has registered with RERA are apartment projects: 5 in 10. In the rest of Rajasthan it is about 3 in 10. This counts every year together: among new registrations, plotted schemes have led in Jaipur since 2025 (see: Plotted schemes lead).

What it means for a consultantA statewide trend in plotted colonies does not describe Jaipur's stock. For a Jaipur feasibility or product-mix note, use Jaipur's own register.

What it means for the clientMost of the state's registered apartment projects are in Jaipur. A buyer or developer there is in a different market from the rest of the state.

Where it stops RERA counts projects, not homes. One tower and one colony each count as one, so this says nothing about how many flats or plots there are.

How I know
  • What I read. RERA Rajasthan's public search. RERA is the state's register where builders must file each new project. I filtered it by district and by project type.
  • How I compared. Group housing projects as a share of all projects, Jaipur district against the rest of the state.
  • How sure. It is the whole register, not a sample. I read it twice, and the types add up exactly to the totals.

How I checked it

I tried to break this finding. Each line asks one question a doubter would ask.

  • Do the types add up? Yes: the type counts sum exactly to each total.
  • Was it read right? The search was read twice, with the same counts.
  • Is it a recent swing? No: it is the whole register to date, every year together. For the recent shift towards plotted schemes, see Plotted schemes lead.

What this does not show

  • Not homes. A tower of many flats and a small colony each count once.
  • Not sales. Registration says a project was filed, not that it sold.
  • Not quality or progress. The count says nothing about whether projects were built.

The tests behind this (for analysts)

For analysts: what each test asked, and what it found. The technical name is in brackets.

  • Is a sampling test needed? No: this is a complete count of the register, so there is no sampling error. (Census count, read twice.)
  • Do the parts match the whole? Type counts sum exactly to the district totals. (Internal consistency check.)

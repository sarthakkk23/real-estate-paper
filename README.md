# The Real Estate Paper

Free, independent figures on Jaipur real estate, from public records: JDA's plot auctions, RERA Rajasthan, the
state's registrations and circle rates, and NHB RESIDEX. By Sarthak Oberoi, a data analyst in Jaipur.

**Site:** https://sarthakkk23.github.io/real-estate-paper/

This repo holds the built site only. Every number on a page is computed by code and recomputed by separate code
before it goes up; the aggregated tables are in [`data/`](data/). Nothing is shown per plot, deed, project or colony.
Nothing here is for sale, and no business pays to appear.

Part of [Pink City Papers](https://sarthakkk23.github.io/pink-city-papers/), with
[The Café Paper](https://sarthakkk23.github.io/cafe-paper/) and
[The Jewellery Paper](https://sarthakkk23.github.io/jewellery-paper/).

Limit

Built on April 2024 to October 2026 only, so each month appears just two or three times in each district. Sale deeds of every kind are counted, not new homes.

Source

For analysts

How this was tested (for analysts)
  • Each month is compared with April inside the same district and the same year, so a district that is busy all year, or a busy year, does not pass for a season (district-by-year fixed effects, errors clustered by district).
  • The range beside each month is how far the true figure could reasonably be from it (the 95% range).

Where this is used

No playbook case uses this tool; it sits beside the finding that there is no reliable month to bid.

Tool · Stamp-duty base from a circle rate

On what value will stamp duty be charged: the price, or the circle-rate value?

Use this when you need the value the registry will charge duty on, and the price agreed may be below the circle-rate value.

Use
Where the plot sits
Width of the road it faces
Look up your colony and use on the state's e-Panjiyan portal and type the rate it lists. I do not show circle rates here: the portal's terms do not allow them to be reproduced.
Rate per

Some rows the portal labels per sq ft are in fact per sq m. If a rate marked sq ft looks about ten times larger than the other sq ft rows near it, it is per sq m: choose sq m.

Area in
Leave it empty to see the circle-rate value alone.
Typed in

Type the circle rate you read on the portal.

How sure

No range: for a road up to 40 ft the listed rate is used as it is.

Limit

Describes Jaipur's current circle-rate table in the 27 offices that list urban rates, read 13 November 2026. Check your row on the portal: some rows labelled sq ft are in sq m. Circle rates are the state's minimum values for stamp duty, not prices.

Source

The state's circle-rate (DLC) table on e-Panjiyan, every row in the 27 offices that list urban rates, read 13 November 2026. Rule on the higher of price and circle-rate value: the State's notification of 8 March 2016.

These are not legal or tax advice. At the registry, the registering office's own figure is the one that counts.

For analysts

How this was tested (for analysts)
  • I counted every row of the current table, not a sample: for each road width I compared each row's rate with the same row's rate for the narrowest road (a complete count of the table).
  • Interior rows were measured the same way against the same row's road-facing rate, and the spread was too wide to apply one figure (median, with the tenth and ninetieth percentiles).
  • A second, separate script reads the steps and shares again and must agree (independent cross-check).
  • The page's own sums are run on worked cases and must match a second, separately written version to the rupee.

Where this is used

The playbook case that uses this tool:

  • The circle rate was revised. What changes in my cost line?
